# Synthetic media pilot v1

Five self-authored engineering cases exercise actual media derivation: OGG/Opus speech, a PNG showing a party together, a JPEG showing split destinations/count, a silent waiting-to-assigned MP4 and an MP4 whose speech qualifies approval. These are simple generated cards/Windows speech, not real group media or a held-out public benchmark. The manifest freezes each file hash, rubric, literal checks and runtime identity before the first paid media call. Raw fixtures remain ignored and are deleted after the pilot.

Offline preparation uses the verified optional FFmpeg 9.0.2 toolchain and installed Windows speech/fonts, with only OS environment settings. `npm.cmd run prepare:media-offline` builds and invokes `scripts/prepare-media-pilot.mjs`. The initial preparation was run directly after the build; it produced five validated inputs with zero model calls. It refuses an existing fixture directory or pilot capture. No microphone, third-party TTS service or key is used for creation. See docs/CODECS.md for native tool setup.

`npm.cmd run test:media-live` is a fixed Infisical testing route, separate from CI and the MOCK conversation terminal. It permits at most five media inferences using the shared locked `.local/state/teammate.sqlite` ledger and conservative USD 5 total ceiling, preserving any lower configured cap. It cannot launch a shell, coding agent or Discord. Expected answers/rubrics are grader data; only supplied bytes and fixed generic media instructions reach the provider.

Voice uses Muse Voice Transcribe. Images/silent video use Spark 1.3 Standard; only the explicitly audio-important clip uses Spark 1.2 Standard, with 4000 output/reasoning tokens as its documentation recommends. Visible descriptions retain the 1800-character limit. All calls reserve before dispatch and have no automatic retry/fallback. Visual reservations assume the entire published context capacity rather than compressed file size. Unknown charges stay reserved. Each video upload must be deleted by its exact returned safe file ID; uncertain cleanup blocks a later video upload and is not hidden.

The scoped pipeline must expose a labelled observational source to authorized local context, create no approval, revoke its derived text on original removal and purge only the new test project's content without resetting charges. Only this pilot's resolved fixture directory can be recursively deleted. Raw synthetic descriptions and the exact preserved first-attempt capture stay separately ignored under `.local/evidence/media-pilot-v1.json`; deleting database/fixture content does not erase that capture.

Five generated descriptions alone are not a pass. Record literal checks unchanged, failures, source lifecycle and upload cleanup. Then inspect the actual returned descriptions against the predefined semantic rubrics. The target is at least four of five correct cases, with reviewer identity/limitations explicit. An agent review is not a human rating, real group use or broad media-quality certification. Never overwrite/rerun a failed case to improve the count; retain this run and version a distinct later experiment if needed.
